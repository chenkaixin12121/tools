# DevKit — 开发者工具箱

九个常用开发工具的离线合集。纯静态页面，所有计算都在浏览器里完成，输入的内容不会发往任何服务器。

用浏览器直接打开 `index.html` 即可，无需构建、无需安装依赖。

## 工具清单

### JSON 工具

处理结果固定以树结构展示，可逐层折叠。除校验和格式化外，还能对左侧输入做转义处理：

- **添加转义** — 转成可嵌入字符串字段的形式（`"` → `\"`，换行 → `\n`）
- **去除转义** — 还原转义后的内容，兼容带引号包裹和不带引号两种写法
- **压缩** — 去掉所有空白

转义和去转义**不要求输入是合法 JSON**，任意文本都能用 —— 把 SQL、日志或 HTML 片段塞进 JSON 字段时直接拿来处理。控制字符按 JSON 规范转义，`\b`、`\f` 以及 `\u0000`–`\u001F` 都能正确往返。

只有校验、树视图和压缩需要合法 JSON。内容不是 JSON 时状态行显示中性提示而非报错，写坏的 JSON（以 `{`、`[`、`"` 开头却解析失败）才会红字标出具体错误。
- **全屏编辑** — 长 JSON 可进入全屏模式

底部状态行显示节点总数、最大深度和字符数。

大体量 JSON 有性能保护：深度超过 2 层的节点默认折叠且不创建 DOM，单层每批渲染 100 条，其余点击加载。128 KB 的接口返回只生成约 400 个 DOM 节点，不会卡住页面。

### Cron 在线解析

同时支持两种格式：

- Unix 五段 —— 分 时 日 月 周
- Spring 六段或七段 —— 秒 分 时 日 月 周 [年]

可以直接粘贴 Java 注解，会自动提取里面的表达式：

```
@Scheduled(cron = "0 55 */2 * * ?")
```

字段支持 `*` `?` `,` `-` `/`，月份和星期可用英文缩写（`JAN`、`MON`）。解析后给出逐字段含义拆解和接下来 5 次执行时间。

执行时间按你的本机时区计算和展示，界面上会标出当前时区。对于 2 月 30 日这类永不成立的组合，会直接判定无解而不是空转。

### 时间戳转换

Unix 时间戳与本地日期时间双向转换，秒和毫秒都支持，可一键填入当前时间。

### 正则表达式测试

边输入边匹配，支持 `g` `i` `m` 修饰符，列出每条匹配的内容和起始位置。结果最多显示 100 条。

### Markdown 预览

左侧编辑右侧实时预览。支持一到三级标题、有序与无序列表、引用、代码块、行内代码、粗体、斜体、分隔线，以及 http/https 链接。

点「示例」载入一段涵盖上述全部语法的开发笔记，可作为渲染效果的参照。

### bcrypt 生成器

生成密码哈希，成本因子可在 4–14 之间调节（默认 10），同时显示哈希长度。数值越高计算越慢。

### RSA 密钥生成

通过浏览器的 Web Crypto API 在本地生成密钥对，可选 2048、3072、4096 位，输出 PEM / PKCS#8 格式。

私钥同样只存在于当前页面，刷新即消失。

### JWT 解码器

解出 Header 和 Payload，自动识别并去掉 `Bearer ` 前缀。若 Payload 里含有 `iss`、`sub`、`exp`、`iat`，会单独列出，时间字段转成可读格式。

**不验证签名。** 这个工具只做解码，不能用来判断 Token 是否可信。

### 随机密码生成

用 `crypto.getRandomValues` 生成，长度 8–64（默认 16），一次可生成 1–20 个。

四类字符可独立开关，且已排除形近字符以免抄错：小写去掉 `l`，大写去掉 `I` 和 `O`，数字只用 2–9，符号取 `!@#$%^&*_-+=`。勾选的每一类都保证至少出现一个。

## 界面

深浅两套配色，右上角切换，选择会记住；首次打开跟随系统偏好。

深色是琥珀磷光屏的路子，亮色不是它的反色，而是打印终端的纸配印刷棕橙。两套的文字对比度都达到 WCAG AA。

编辑区高度跟视口联动，屏幕越高编辑区越大。窄屏下侧栏收成顶部图标条，编辑区改为上下堆叠。

## 依赖

两个 CDN 脚本：

- [Lucide](https://lucide.dev) 0.468.0 — 图标
- [bcryptjs](https://github.com/dcodeIO/bcrypt.js) 2.4.3 — bcrypt 哈希计算

除 bcrypt 面板外，其余工具在脚本加载失败时仍可正常使用。

> 这两个脚本目前没有配置 SRI（`integrity` 属性）。若部署到公开环境，建议补上完整性校验，或把依赖改为本地托管。

## 文件结构

```
index.html    页面结构，九个工具面板
app.js        全部逻辑，无框架无构建步骤
style.css     样式与深浅主题的 token 定义
CNAME         GitHub Pages 自定义域名（部署前需替换为真实域名）
DEPLOY.md     部署到 GitHub Pages 与配置域名的步骤
```

## 部署

GitHub Pages 从 `main` 分支根目录直接发布，推送即生效，无构建步骤。
详见 [DEPLOY.md](DEPLOY.md)。

## 隐私

所有处理都在浏览器本地完成，没有任何网络请求发送你的输入内容。页面不做持久化存储，唯一写入 localStorage 的是主题选择。密码、密钥、Token 一律刷新即失，也不会留在历史记录里。
